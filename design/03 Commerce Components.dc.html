ProductCard — anatomy & states

Hover (desktop only)Border → Border Strong. Image scale 1.03 (single image) or crossfade to second image (image-swap). Quick add fades up 4px. No shadow, no lift by default; “subtle-lift” is an opt-in global card hover.
Touch (tablet / mobile)No hover state. Quick add renders as a persistent 40px icon button bottom-right of media, or is hidden. Whole card is one link; swatches are non-interactive previews in the card.
Quick add behaviorSingle variant → adds directly, button shows Adding… (width held) then Added (Primary fill) for 1.5s, cart badge pulses. Multiple variants → opens variant picker in a popover (desktop) or bottom sheet (mobile).

ProductMedia · ProductGallery
main media · contain · click to zoom Sale
  • Desktop: vertical thumbnails (72px) left of main; > 6 thumbs scroll within the main height. Selected thumb: 2px inset Primary. Arrow keys move selection.
  • Zoom: click opens full-viewport lightbox (Modal shadow, pinch/scroll zoom, Esc closes). Zoom affordance is a bordered 40px icon button, bottom-right.
  • Video: thumbnail shows play glyph; main stage plays inline muted with native controls; never autoplays with sound.
  • Variant change: main crossfades Standard to the variant’s image and moves selected thumb. No scroll jump.
  • Alternate desktop layout “stacked”: all media in a 2-column grid, page scrolls; purchase column sticky.
