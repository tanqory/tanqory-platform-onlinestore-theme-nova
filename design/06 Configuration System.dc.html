Responsive fallback rules

desktop columnstablet (auto)mobile (auto)
{{ f.d }}{{ f.t }}{{ f.m }}
  • Merchants set desktop values; tablet is always derived; mobile is derived unless a Mobile-group override is set.
  • Sizes (hero, spacing, type) step down one tier per breakpoint automatically.
  • Carousels show 4.3 / 2.5 / 1.2 items regardless of column setting.
  • Split layouts stack below 768 with media first unless mobileMediaPosition says otherwise.
  • Alignment: center on desktop → left on mobile by default (mobileContentAlignment overrides).
